# Warehouse Predictive Maintenance

A Streamlit machine-learning application that estimates equipment failure risk for conveyors, forklifts and sorters using operational sensor readings.

## Why it matters
Unexpected equipment downtime disrupts throughput and labor plans. A ranked maintenance queue lets managers inspect the highest-risk assets first.

## Capabilities
- Reproducible synthetic sensor data
- Failure-risk model with probability scores
- Asset health KPIs and risk segmentation
- Maintenance priority queue
- Feature importance for explainability
- Automated tests

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Technology
Python · pandas · scikit-learn · Streamlit · Plotly · pytest

This is an original portfolio implementation using synthetic data.
